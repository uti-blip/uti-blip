# Enzo Buidine

**Product design · Interactive prototypes · Creative development**  
Paris, France

I turn ideas into interfaces people can explore: document review tools, AI evidence workflows and interactive 3D spaces. I founded **Lexia** and direct the experience of **BUIDINE Galerie**.

My work connects product scope, visual identity, interaction design and working prototypes. I use coding agents for implementation and iteration, and make the product and design decisions behind the result.

### RFQ Review — from a discrepancy to its source

[![RFQ Review — side-by-side requirements, source excerpts and human review](https://github.com/user-attachments/assets/27333b7e-6e5b-46e7-9f16-fcc63c66b260)](https://v1-revue-rfq-enzo.netlify.app/app?lang=en)

<sub>Interface detail · quantity discrepancy, source excerpts and review controls. Synthetic documents.</sub>

A request and supplier quote show **100 units**; the purchase order shows **150**. The reviewer can compare the documents, open the source excerpt and make a review decision in the same flow.

**My contribution:** workflow, information hierarchy, review states and agent-assisted implementation.  
**Try it:** inspect the quantity mismatch, reveal the source, then use the review controls.

## How I work

- **Frame the workflow:** identify the information, actions and decisions the interface needs to connect.
- **Give it a visual language:** work across identity, typography, motion and interaction.
- **Build and review:** prototype with coding agents, inspect behaviour and revise the result.
- **Keep the evidence visible:** distinguish public demos, local prototypes and what still needs validation.

Across these projects I work with **React, TypeScript, Next.js, Python/FastAPI, PostgreSQL, SQLite and Three.js**, alongside GitHub Actions, Vercel and Netlify. These are project technologies; the catalogue explains where each is used.

I'm interested in **product design, founding designer and product generalist** opportunities where I can connect product thinking, visual craft and implementation.
